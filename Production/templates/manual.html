Recommended Client Demo Flow

  1. Register/login and explain the secure company node.
  2. Show the dashboard and the 20 modules.
  3. Create a sample production batch with buyer, fabric, quantity, QC and warehouse information.
  4. Explain that the batch receives a unique DPP token.
  5. Demonstrate the Product Scanner.
  6. For a phone: choose Scan with Mobile Camera, allow camera access and point at the QR/barcode.
  7. For a USB/Bluetooth scanner: choose Use Scanner, scan the label and let the scanner type the code into the input.
  8. Show the returned batch details, QC and status.
  9. Demonstrate a few department modules and then Reports.
  10. Finish with tenant isolation, security and production-readiness points.

Mobile & Camera Notes

  • The dashboard uses a mobile drawer for the 20 modules.
  • Forms and action buttons adapt to smaller screens.
  • Camera scanning uses the browser's camera permission and BarcodeDetector where supported.
  • For deployed production use, camera access normally requires HTTPS.
  • If a browser does not support automatic barcode detection, use the manual input or USB/Bluetooth scanner option.
